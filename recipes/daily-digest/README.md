# daily-digest — one finding a morning, or none

| file | what it is |
|---|---|
| [recipe.toml](recipe.toml) | one job at 09:00, `report` only |
| [digest.md](digest.md) | the playbook: tracker, CI, the day's commits, the automation's own health → one finding |

The whole value is in what it leaves out: a quiet day produces nothing, a thing reported
yesterday and unchanged is not repeated, and the automation's own failures are on the list so a
loop that has been failing for a week does not hide behind the other loops' silence.
